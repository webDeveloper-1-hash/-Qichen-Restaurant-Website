## 📋 Overview

A premium, fully responsive restaurant website for **Qichen Restaurant** featuring elegant design, smooth animations, and complete functionality including menu display, online booking, banquet facilities, catering services, and contact information.

## ✨ Features

### 📄 Pages Included
- **Home** - Hero slider with animated content
- **About Us** - Restaurant story, mission, and features
- **Menu** - Categorized menu items with prices
- **Banquet Facility** - Event spaces with capacity details
- **Catering** - Catering services and packages
- **Gallery** - Filterable photo gallery with lightbox
- **Contact** - Contact form, map, and information
- **Visiting Hours** - Complete schedule with happy hours
- **Online Booking** - Table reservation system
- **Menu Kit** - Downloadable menu section

### 🎨 Design Features
- ✅ Modern & premium design
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Smooth animations and transitions
- ✅ Gradient text effects
- ✅ Custom scrollbar
- ✅ Glassmorphism effects
- ✅ Clean and clear typography

### 🔧 Functionality
- ✅ Auto-playing image slider
- ✅ Category-based menu filtering
- ✅ Gallery filtering by category
- ✅ Lightbox for images
- ✅ Form submissions with validation
- ✅ Newsletter subscription
- ✅ Google Maps integration
- ✅ Social media links
- ✅ Smooth scroll navigation
